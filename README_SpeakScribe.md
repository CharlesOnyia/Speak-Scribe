
# 📢 SpeakScribe  
*A voice-to-text feedback platform for inclusive, frictionless, and multilingual reviews*

---

## 🧩 Problem  
Leaving reviews is harder than it should be:  
- Typing takes time and effort  
- People often don't know what to say  
- Language barriers prevent global participation  
- Reviews are skewed toward extreme opinions  

Result: Customers hesitate to buy. Businesses miss valuable insights.

---

## 💡 Solution  
**SpeakScribe** lets users quickly leave reviews by speaking, not typing.

Core Features:
- 🎙️ Tap-to-speak review input  
- 📄 Auto-transcription with editable text  
- 🌍 Automatic language detection and translation  
- 🔁 “View Original / View Translation” toggle  
- 🔒 Privacy-respecting: No stored audio, just clean text

## ⚙️ Technical Overview  
- **Platform:** Replit  
- **Languages:** HTML, CSS, JavaScript  
- **Core Tools:**  
  - Web Speech API (for voice input)  
  - Language auto-detection logic  
  - Placeholder translation logic (expandable to Google Translate API or DeepL)  

> Future integrations could include Whisper, OpenAI API, or Google Cloud for improved accuracy and multilingual support.
